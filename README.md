# 🐂 QurbaniHat — Modern Sacrificial Livestock Marketplace

A feature-rich, full-stack marketplace web application built to connect cattle buyers and sellers seamlessly during Eid-ul-Adha.

---

## 🌐 Live Demo & Resources

* 🔗 **Live Website:** https://qurbani-eid-hat.vercel.app
* 📁 **Repository:** https://github.com/Tanvirislam855/qurbani-eid-hat

---

## ✨ Key Features

* 🔐 **Secure User Authentication:** Sign up, sign in, and session management using JWT / NextAuth.
* 🐄 **Livestock Listings & Filtering:** Browse cattle with dynamic category and price filtering.
* 🔍 **Search Functionality:** Real-time search to instantly find specific animals or sellers.
* 📱 **Responsive UI/UX:** Fully optimized mobile-first design with smooth Tailwind styling.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Library:** React 19
* **Styling:** Tailwind CSS v4
* **Auth:** JWT / NextAuth
* **Database:** MongoDB / Mongoose

---

## 🚀 Getting Started

### 1. Clone the repository
git clone https://github.com/Tanvirislam855/qurbani-eid-hat.git
cd qurbani-eid-hat

### 2. Install dependencies
npm install

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory:
MONGODB_URI=your_mongodb_connection_string
NEXTAUTH_SECRET=your_nextauth_secret_key
NEXTAUTH_URL=http://localhost:3000

### 4. Run Development Server
npm run dev

> Open http://localhost:3000 in your browser.
